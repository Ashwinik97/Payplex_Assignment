PAYPLEX ASSIGNMENT - ASHWINI
----------------------------
Features Implemented:
1. User Registration with Profile Photo Upload (Multipart Form Data).
2. Admin Dashboard showing User-wise data.
3. Check Profile: Detailed view showing address, DOB, and actual Photo.
4. Active/Inactive Status Toggle.
5. Status-Based Login: Inactive users are blocked from logging in.

How to Run:
1. Backend: 
   - cd backend
   - pip install fastapi uvicorn python-multipart
   - python main.py
2. Frontend:
   - cd frontend
   - npm install
   - npm start
